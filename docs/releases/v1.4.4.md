# Wandao v1.4.4

**这是一次桌面端稳定性与更新体验增强版本。** Wandao 在保留原有平台能力、任务数据、历史配置和插件机制的同时，修复浏览器选择问题，加入程序内更新，并让已安装插件可以按需卸载。

## 浏览器选择与自动化启动修复

- 修复 Windows 以管理员身份运行或浏览器自定义安装路径时，自动检测不到 Chrome/Edge 的问题。
- 主程序统一把检测到的浏览器路径传给插件，避免设置页检测结果和插件运行时不一致。
- 增加 Windows 注册表和标准安装位置检测。
- 补充 macOS `~/Applications` 下的 Chrome、Edge、Chromium 和 Brave 浏览器检测。
- 修复浏览器检测过程中 Windows 控制台窗口闪烁的问题。
- 支持手动选择浏览器可执行文件，检测到 WebView2 Runtime 时不会误当成完整浏览器。

## 程序内更新

- 接入 Tauri 官方签名更新器，支持检查、下载、签名校验、安装和重启。
- 检测到新版本后会在顶部显示更新提示，由用户确认后下载安装，不会在任务运行时强制重启。
- 更新下载过程中会显示进度，当前任务运行时会阻止更新，避免中断导入导出。
- v1.4.2 及更早版本需要先手动安装本版本；从本版本开始，后续版本可以直接在应用内更新。
- 更新包使用独立签名链，程序会在安装前验证更新包来源和完整性。

## 插件中心改进

- 已安装插件增加卸载功能，方便用户节约磁盘空间。
- 卸载时可以选择是否同时删除插件配置、登录凭证和缓存。
- 插件生成的导出文件不会被卸载操作删除。
- 随主程序提供的内置插件卸载后会恢复为内置版本，不会影响主程序基础能力。

## 更清晰的开源支持入口

- 主界面顶部增加“开源免费 · 点个 Star 支持”入口。
- 点击后会打开万能导 GitHub 项目主页，方便提交问题、查看源码和支持项目。

## 下载与安装

- **Windows x64**：下载并运行 `Wandao-1.4.4-win-x64-setup.exe`。
- **macOS Apple Silicon**：下载 `Wandao-1.4.4-macOS-arm64.zip`，解压后将 `Wandao.app` 拖入“应用程序”。
- **其他系统**：下载源码压缩包后解压，按项目说明启动。

程序内更新所需的签名资产会随正式 Release 一起发布，普通用户无需单独下载签名文件。

当前 Windows 和 macOS 安装包尚未配置商业代码签名，系统可能显示未知发布者或 Gatekeeper 提示；macOS 首次打开请按系统提示在“隐私与安全性”中允许应用运行。
